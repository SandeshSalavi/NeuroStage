## 💡 How We Use This Worksheet

Whenever you work on your laptop using Antigravity or manually:

1. **Before you start:** Check this folder or your teammate's worksheet to see what they recently finished.
2. **When you finish working:** Add a new row to your table in your markdown file (`pankaj.md`, `anurag.md`, or `sandesh.md`).
   - **Date:** Today's date
   - **What I Done:** Quick summary of your task or experiment
   - **How I Done It / Files:** Which files you touched or commands you ran
   - **Results:** What worked, what output was produced
   - **Status:** Done / In Progress
   - **What I Will Do Next:** Next task you plan to do
3. **Using Antigravity:** You can simply tell Antigravity in chat:
   > *"Update my worksheet in worksheets/<your-name>.md with what we did today"*
   and Antigravity will automatically write the entry for you!
4. **Push to GitHub:**
   ```bash
   git add .
   git commit -m "docs: update worksheet for <your-name>"
   git push origin <your-branch>
   ```

Because each person has their own file, **you will never get git merge conflicts** when updating your worksheet!
